Python 3.9+
use the command to install dependancies 
pip install -r requirements.txt

Backend Fast API with Authentiation with Login, Register, Doctors Page 
still work in Progress to add more component.

Authenticated patients can book and cancel appointments at `/appointments/`.
Doctors and admins can view requests and update their status.
Admins can access all appointments; patients can access only their own, and
doctor accounts are matched to doctor records by email to restrict access to
their appointments.
